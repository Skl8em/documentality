`propose` opens a future for deliberation.
It sits **at the floor** (`intention: state`): it serves by putting a case and its alternatives before a reader who must be able to *decide*, not merely agree.
Use [`template.md`](template.md) to write one.

- **Generative verb:** *argue.*
- **Stake:** the case, and the alternatives considered.
  A proposal that states a preference without arguing it against the alternatives is a request, not a proposal: it invites a yes/no, not a decision.
- **Move structure:** establish the territory (the shared situation) → identify the problem or gap → build the case for the proposed course, treating alternatives fairly → make the explicit ask.
- **Failure mode:** asserting a preference as if obvious, skipping the alternatives — leaving the reader able only to agree or refuse, not to decide.
- **Genres:** RFC, requirements document, design proposal, PRD, pitch.

Recipient note: a `propose` is a **current** deliberation; when it closes it **decants** into a frozen `decide` record (the state/change seam).
Keep it live and revisable until then.
